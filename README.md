# energo_bot

Telegram bot which forecasting status of light at the home

## Режими роботи

На початку (`/start`) користувач обирає режим. Змінити його можна в будь-який момент кнопкою
«Змінити режим» або командою `/mode`.

- **🏠 Стандартний** — моніторинг світла за адресою (за замовчуванням Богдана Хмельницького 67а).
  Бот раз на пару хвилин питає Tuya Cloud, чи пристрій онлайн, і пише всім користувачам
  цього режиму «🔴 Світло зникло о 14:05» / «🟢 Світло з'явилось о 17:30, не було 3 год 25 хв».
  Кнопка «🔄 Оновити» показує поточний стан будь-коли. Сповіщення про зникнення і появу
  світла можна вимкнути й увімкнути кнопкою «🔕 Вимкнути / 🔔 Увімкнути сповіщення»
  (за замовчуванням увімкнені). Нічого додавати не потрібно.
- **🛠 Розширений** — моніторинг IP-адрес: бот пінгує їх кожні N хвилин (`IP_CHECK_MINUTES`).

Користувачі, які вже мали IP-адреси, автоматично лишаються в розширеному режимі.

## Інтерфейс

Уся взаємодія йде через інлайн-кнопки під одним повідомленням-панеллю: натискання змінює це
повідомлення на місці, а тексти, які користувач вводить (IP-адреса, опис), бот видаляє. Сповіщення
про світло теж стають новою панеллю, стара видаляється, тож у чаті завжди одне-два повідомлення.
Команди: `/start`, `/menu`, `/version`, `/restart` (розширений режим), `/admin` (лише адмін).

## Запуск

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env     # і заповнити
.venv\Scripts\python bot\bot.py
```

## Налаштування `.env`

| Змінна | Призначення |
| --- | --- |
| `BOT_TOKEN` | токен від @BotFather (обов'язково) |
| `TUYA_ACCESS_ID`, `TUYA_ACCESS_SECRET` | ключі Cloud-проєкту Tuya (для стандартного режиму) |
| `TUYA_ENDPOINT` | дата-центр проєкту, за замовчуванням `https://openapi.tuyaeu.com` |
| `TUYA_LOCATION` | адреса в стандартному режимі, за замовчуванням «Богдана Хмельницького 67а» |
| `TUYA_DEVICE_ID` | стежити лише за цими пристроями (через кому); без нього — за всіма пристроями акаунта |
| `TUYA_POLL_SECONDS` | період опитування Tuya, за замовчуванням 120 |
| `TUYA_CONFIRM_POLLS` | скільки опитувань підряд підтверджують зміну, за замовчуванням 2 |
| `IP_CHECK_MINUTES` | період пінгу IP-адрес у розширеному режимі, за замовчуванням 10 |

Без `TUYA_ACCESS_ID` / `TUYA_ACCESS_SECRET` бот працює, але лише в розширеному режимі.

## Як підключити пристрій Tuya

1. Пристрій додано в застосунок Smart Life, він онлайн. Вмикати його треба у звичайну розетку, не в ДБЖ.
2. На [iot.tuya.com](https://iot.tuya.com) → Cloud → Development → Create Cloud Project
   (Industry: Smart Home, Development Method: Smart Home, Data Center: Central Europe для України).
   Залиште API-сервіси за замовчуванням (IoT Core, Authorization Token Management, Smart Home
   Basic Service) → Authorize.
3. У проєкті, вкладка Overview: скопіюйте **Access ID** і **Access Secret** у `.env`.
4. Вкладка Devices → Link App Account → Add App Account: відскануйте QR у Smart Life
   («Я» → значок сканера). Після цього пристрій з'явиться в списку Devices.
5. Cloud → Cloud Services: переконайтесь, що IoT Core активний (безкоштовний доступ періодично
   треба продовжувати кнопкою на сайті).

Tuya помічає розрив зв'язку із запізненням 1–3 хвилини, тож сповіщення приходить не миттєво.
